# My AI Wordbook

iPhone向けの自分専用AI英単語帳です。

## 実装済み

- 英単語を1語ずつ入力
- OpenAI APIで自動生成
  - 日本語訳
  - 品詞
  - 発音記号
  - 英語例文
  - 例文の日本語訳
  - TOEIC重要度 1〜5
  - TOEIC 600/700/800/900 の推奨レベル
- 金フレ型の「単語→タップ→答え表示」
- 発音（iPhoneの音声合成）
- ○/△/×の3段階評価
- SRS（間隔反復）
- TOEIC 600/700/800/900などの単語帳
- 単語検索
- バックアップ／復元
- PWA対応（ホーム画面に追加可能）

## 重要：APIキーについて

この簡易版は、iPhoneのブラウザからOpenAI APIへ直接アクセスします。
APIキーはブラウザのlocalStorageに保存されます。

したがって、**自分専用・自分のiPhoneだけで使う用途を想定**しています。
Webサイトを公開して他人に使わせる場合は、この方式を使わず、APIキーをサーバー側に置く構成へ変更してください。

## 使い方

1. このフォルダをHTTPSで配信できる場所に置く。
   GitHub Pages / Cloudflare Pagesなどが利用できます。
2. iPhoneのSafariで開く。
3. 「追加」→ OpenAI APIキーを入力→保存。
4. 英単語を入力。
5. 「AIで翻訳してカードを作成」。
6. ホーム画面から「今日の学習を開始」。

## API料金

AIカード生成にはOpenAI APIの従量課金が発生します。
料金は使用するモデルによって異なるため、最新の料金表を確認してください。
